## ✦ About CareerCopilot AI

**CareerCopilot AI** is a next-generation career intelligence platform that combines AI-powered resume analysis, semantic job matching, autonomous application workflows, and real-time analytics into one unified operating system for your career.

The platform ingests your resume, extracts skills, experience, and education using NLP pipelines, generates vector embeddings for semantic search, matches you against thousands of live job listings with AI scoring, generates personalized cover letters, and queues applications for autonomous submission — all with real-time tracking and notification delivery.

It is built for professionals who want to stop manually applying and start leveraging AI to scale their job search.

## ✦ AI Pipeline Flow

```
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────────┐
  │  RESUME  │───▶│ PARSE &  │───▶│ SKILL    │───▶│  EMBEDDING   │
  │  UPLOAD  │    │ EXTRACT  │    │ ANALYZE  │    │  GENERATION   │
  └──────────┘    └──────────┘    └──────────┘    └──────┬───────┘
                                                          │
                                                          ▼
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────────┐
  │  APPLY   │◀───│ QUEUE    │◀───│ AI MATCH │◀───│  SEMANTIC    │
  │  WORKER  │    │ MANAGER  │    │ SCORING  │    │  SEARCH      │
  └──────────┘    └──────────┘    └──────────┘    └──────────────┘
       │
       ▼
  ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ COVER    │───▶│ SUBMIT   │───▶│ TRACK    │
  │ LETTER   │    │          │    │ STATUS   │
  └──────────┘    └──────────┘    └──────────┘
```

**Pipeline phases:** `initializing` → `searching_jobs` → `matching_jobs` → `queuing_applications` → `completed`

Each phase is persisted to MongoDB. On server restart, the engine auto-recovers interrupted pipelines and marks them for manual resume — no lost state.

## ✦ Automation Engine

The **Auto Apply Engine** is a persistent, MongoDB-backed background processing system that autonomously manages the entire job application lifecycle.

| Component | Description |
|-----------|-------------|
| **Pipeline Engine** | Orchestrates the full flow — search, match, queue, notify. State persisted in MongoDB, survives server restarts |
| **Semantic Matcher** | 5-factor weighted scoring (skills 35%, semantics 25%, title 15%, experience 15%, industry 10%) |
| **Queue Manager** | Priority-based FIFO queue with retry logic, daily limits, and status tracking |
| **Apply Worker** | Background worker that dequeues and processes applications via browser automation or mock submission |
| **Notifier** | Creates in-app notifications on pipeline start/complete/fail and per-application submission |
| **Session Manager** | Stores platform authentication sessions (LinkedIn, Naukri, Indeed, etc.) for browser-based auto-apply |

## ✦ Installation

### Prerequisites

- Node.js 18+
- Python 3.11+
- MongoDB instance (local or Atlas)
- OpenAI API key (or OpenRouter)

### Clone

```bash
git clone https://github.com/Srikar-Merugu/careercopilot-ai.git
cd careercopilot-ai
```

### Frontend Setup

```bash
cd frontend
npm install
cp .env.example .env.local
# Edit .env.local with your environment variables
npm run dev
```

### Backend Setup

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your environment variables
uvicorn main:app --reload --port 8000
```

## ✦ Deployment

### Frontend (Vercel)

```bash
cd frontend
npx vercel --prod
```

Set environment variables in the Vercel dashboard under Project Settings → Environment Variables.

### Backend (Render)

1. Push to GitHub
2. Create a new Web Service on Render
3. Connect your repository
4. Set:
   - **Root Directory:** `backend`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn main:app --host 0.0.0.0 --port 8000`
5. Add all environment variables from the `.env` file

### Docker

```bash
# Build backend image
docker build -t careercopilot-backend ./backend

# Run container
docker run -p 8000:8000 --env-file ./backend/.env careercopilot-backend
```

## ✦ Security & Performance

- **JWT-based authentication** with configurable token expiry
- **Rate limiting** middleware (60 requests/minute per client)
- **CORS protection** with allowed origins whitelist
- **Async workers** using asyncio for non-blocking job processing
- **MongoDB indexes** on user_id, status, and created_at for fast queries
- **Optimized embeddings** with text truncation (2000 chars) and caching
- **Graceful degradation** — semantic matching falls back to keyword matching if embedding service is unavailable
- **Pipeline recovery** — interrupted pipelines detected and marked on server restart, preventing stuck "running" states
